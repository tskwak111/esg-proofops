# 전체 범위 추적표

상태 열의 “기반 있음”은 서비스 성능 검증 완료를 의미하지 않는다.

| ID | 기능 | 담당 | 현재 기준 | 완료를 확인하는 증거 |
|---|---|---|---|---|
| A01 | 등록·회사·원본·문서버전·권한 | A | 기반 있음 | 다른 tenant 접근 거부, 원본 hash 불변 |
| A02 | E 소주제+환경 Data+Appendix 분류·파싱 | A | 기반 있음 | 정답 페이지와 범위 비교, 누락/읽기 실패 표시 |
| A03 | 문맥 보존·원자 주장 추출 | A+D | 실제 호출 경로 | split/merge/누락 정답 비교, source 위치 |
| A04 | 관련 근거 검색·기간/범위/셀 귀속 | A+D | 병목 개선 중 | 반례의 잘못된 연결 거부, 누락률·보류율 |
| A05 | 표·단위·연도·각주 조건·수치 | A+D | 조건 연결 잔여 | 숫자 tuple와 조건의 원문 일치, 계산 실패 구분 |
| A06 | 고정 packet 태깅·독립 replica·인용 검증 | A | 경로 있음 | 실제 응답 receipt·예산·재실행 기록 |
| A07 | G/P/M·특칙·미정 gate | A+D | 엔진 있음 | 승인 truth table 회귀, grade/label 결정론적 재현 |
| A08 | 보증·산업·유예·세이프하버 | A+D | 기반/미정 혼재 | 적용범위/제외/미정 구분, 법적 승인 없는 확정 금지 |
| A09 | 검토 수정·If-Match·새 판정·불변 보고서 | A | 기반 있음 | 실제 수정과 경합·export snapshot 검사 |
| B01 | DART·XBRL·주석 원본/가용성 | B | 신규 | corp/fy/rcept/scope별 조회 및 원문 보존 |
| B02 | 공시 패키지·정정·기간·연결 기준 | B(검증), A(저장) | 신규 | 다른 회사·연도·별도 혼입 거부 |
| B03 | C1 조직경계 비교/설명 | B+D | 신규 | entity/facility 혼동·동일 개수 반례 |
| B04 | C2 기간 및 수집 시차 설명 | B+D | 신규 | 기간 일치/차이/설명/모호한 연도 사례 |
| B05 | C3 금액 약속·CAPEX·약정 | B+D | 신규 | 임계값·계정 승인, 0/결측·다년 반례 |
| B06 | C4 분류 정의·산정기준 공시 | B+D | 신규 | 숫자 일치와 정의 존재 분리, 부재 검색 coverage |
| B07 | C5 차단·금지 문구·보류 | B+D | 신규 | stage2 호출 불가, 회계판단 유혹 최소10건 |
| X01 | 연계 revision·API·화면·보고서 | A+B | 신규 | 기존 grade 불변, 양쪽 원문·reason·미실행 표시 |
| D01 | 원문 gold·split·규칙·acceptance | D+A | 추가 필요 | 독립 주석/수정 이력, 평가용 유출 방지 |
| O01 | 비용·실패 재시도·권한·복구·배포 | A | 로컬 기반 | 실제 대상 환경 검증, 미실행 항목 공개 |
| O02 | 데모·평가표·실행 안내·한계 | A+B+D | 추가 | 새 환경 재현·대표 실패/보류 시연 |
| P01 | 광고 별도 모드 | A+D | 기존 P1 유지 | 승인 전용 규칙 없으면 실행 차단; 공시 grade와 분리 |
| P02 | 다년도 비교 | A+D | 기존 P1 유지 | 다년도 원본 확보시 비교, 미확보시 not_run |

P1/승인 전 기능은 삭제가 아니라 원문 단계·입력 조건을 유지한다. 제출물에는 위치·상태·실행 조건을 명시한다.
모든 기능의 자동 판정을 켜는 것과 모든 기능의 실행/차단/검토 경로를 구현하는 것을 혼동하지 않는다.
