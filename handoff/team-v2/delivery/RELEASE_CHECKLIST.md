# 전체 완료 판정표

날짜가 지났다고 체크하지 않는다. 증거 없는 항목은 미완료다.

- [ ] 범위: SCOPE_MATRIX의 모든 항목에 구현/미정/검증 상태와 담당이 있다.
- [ ] 원본: 기업·기간·권한·문서 버전·해시·페이지/locator 보존.
- [ ] 추출: E 본문과 환경 Data/Appendix 누락을 평가하고 미판독을 표시.
- [ ] 근거: 후보와 확정 구분, 실제 quote·귀속·연도·범위·단위 확인.
- [ ] 수치: tuple 및 각주 조건 검증, 계산 불가·충돌은 보류.
- [ ] 태깅: 고정 packet·독립 replica·provider receipt·예산 확인.
- [ ] 판정: pure engine·승인 rulepack·truth table·미정 gate.
- [ ] 보증/산업/세이프하버/광고/다년도: 원문 계약과 승인 조건·not_run 보존.
- [ ] 연계: C1~C4·DART 수집·설명 검색·C5 차단. 기존 등급에 영향 없음.
- [ ] 검토: 원문 보기·태그 수정·If-Match·재판정·이전 기록 보존.
- [ ] 출력: 실제 snapshot과 일치하는 보고서, 양쪽 원문·한계·미실행 표시.
- [ ] 데이터: 기업 split, 독립 gold, 규칙 승인 이력. 합성 자료를 gold와 혼합하지 않음.
- [ ] 성능: 요소/주장 precision/recall, 최종 macro F1, 정상차이 오탐, 보류/수정률, 시간·비용.
- [ ] 분모: 정확히 무엇을 평가했는지·표본 수·신뢰구간·보류 포함 여부 공개.
- [ ] CI: lint/type/unit/integration/contract/build/E2E/security 실제 통과 또는 실패 공개.
- [ ] 운영: 대상 환경에서 권한·복구·재시도·예산·버전 rollback 검증.
- [ ] 재현: 다른 개발자가 clone 후 실행할 명령·준비 데이터·설정 설명이 있다.

문서의 정상 차이 오탐률 <5%, DART 조회 성공률 ≥98%는 목표이지 현재 측정치가 아니다.
나머지 지표 합격선은 acceptance.csv에 제안/승인과 실제 관측을 분리한다.
보류 건을 correct negative로 넣지 않고 자동 처리 비율과 검토 시간을 함께 보여준다.
100개 gold가 전체 corpus를 대표한다고 자동 가정하지 않는다. 기업/레이아웃 편향을 확인한다.
