추가 구현 순서와 필요한 데이터
  1. v2.2와 연계 명세 원문을 버전·해시로 보존 → 기존 Master·계약·Task에 차이 반영.
  2. 기존 보고서 중 서로 다른 기업 3~5곳 → DART 기업코드·보고기간 매핑과 실제 재무 주석 확보 가능성 확인.
  3. 공시 패키지·기간·정정공시 계약 → C5 실행 가드·출력 제한 → C1 구현.

  5. 검토 화면·리포트 연결 → 개발에 쓰지 않은 기업으로 평가 → C2·C4 후속.

필요 데이터: ESG 원본 + 같은 기업·기간의 재무공시 원본, 접수번호·연결 기준·정정 이력, 양쪽 원문에 연결된 정답 태그. 초기에는 공개 DART 자료를 사용하고 미공개 재무자료 수용은 별도 계약·접근 통제 대상으로 둡니다.

평가 기준 · 미정 사항 · 비용
  • 주장·요소 추출은 정밀도·재현율, 수치·연도·단위 연결은 정확한 조합과 원문 위치로 평가합니다. 기존 파싱·각주 조건 병목도 계속 평가해야 합니다.
  • 연계 평가는 설명 있는 차이 / 설명 없는 차이 / 일치 / 정상 차이를 포함합니다. 회계 판단을 유도하는 금지 사례도 최소 10건 포함합니다.
  • 정상 차이 오탐률 5% 미만과 DART 조회 성공률 98% 이상은 문서의 목표이며 현재 측정 성능이 아닙니다. 표본 수·기업 분리·검토 대기율을 함께 보고합니다.
  • C3의 5배 임계값, 회계 항목 대응, 공식 조항·규제 적용은 검증·승인 전 확정 기준으로 사용하지 않습니다. 미래 투자 약속의 회계적 타당성을 평가하지 않습니다.
  • Upstage 등 저비용 모델 경로를 유지합니다. 실제 모델 시험의 기존 누적 예산은 USD 10이며, 이 설명 페이지는 모델 호출이나 자료 업로드를 수행하지 않습니다.
