기준은 `bdbe050`, 원문 v2 §4.2–4.6, Master, R6의 지정 사례다.
`FINALS_Q1_POLICY`는 I9를 확장하는 명시적 opt-in이며 기존 기본값·I9/K9 hash는 유지한다.
사전분류·국소 요소 지침, 부정적 admission, 로컬 기간 및 표 선택의 새 hash를 저장한다.
등급 사다리·법적효력·unknown/conflict/unreadable의 의미를 변경하지 않는다.

미래 시나리오의 예상 매출·재무영향 수치는 일반 성과등급으로 게시하지 않는다.
LLM 분류가 범주를 놓치면 범주 재검토로 중단한다. 저장 응답 재생에서도 검증된 해당
원문으로 일반 등급·가능범위를 보류하고 `forward_looking` 후보 및 GAP-001/002를 표시한다.
후보는 확정 범주나 면책 승인이 아니다. 단순 목표·현재 탄소비용 반영은 이 경로로 바꾸지 않는다.

G6의 일반 활동 추진, M4의 일반 확대·추진·설계·촉진, M2의 유관부서 인용을
unknown으로 보류한다. 구체적 별도 인용은 계속 검사하며 원시 응답·기존 revision은 보존한다.
모델 present 없이 Python이 요소 present를 만들지 않는다.

`2025년에는` 같은 연간 관측의 조사 표기는 검증된 단일 원자 로컬 인용·기존 intrinsic
요소에서만 허용한다. 원문 기간을 다시 쓰지 않으며 타 연도·상충·타 문서·전역 수치의
검사는 유지한다. 기존 도메인 기간 파서와 구 정책의 실행 의미는 그대로다.

명시된 환경영향 완화 요소/효과 표의 동일 origin grid에서 번호가 붙은 수단 셀을
보존하고 온도 상향·팬 풍량 최적화 효과를 후보에 포함한다. 실제 원문 offset만 사용한다.
새 span은 기존 셀·원문 검증을 다시 거쳐야 하며 활동 명칭만으로 M1/M4나 등급을 만들지 않는다.

국소 지침은 분류와 각 요소에 필요한 문구만 렌더한다. 기존 16KiB 요청·예산·세 replica·
인용·귀속·보증 가드를 유지하며 관련 없는 사전분류 wire는 이전 렌더러와 동일하다.
저장 응답의 누락/값 불일치는 그대로 남긴다. 새 모델 응답은 새 평가 산출물로 분리한다.

공개 API/DB column/schema, migration, dependency 변경은 없다. 내부 settings/job artifact의
정책 필드를 추가한다. 이전 실행은 기존 pin으로 읽고 재개한다. rollback은 Q1 신규 배정을
중단하고 Q1 reader를 기존 Q1 산출물에 유지한다. 미지원 reader는 새 hash를 거부해야 한다.
기존 보고서·태깅·판정 revision을 재작성하지 않는다.
