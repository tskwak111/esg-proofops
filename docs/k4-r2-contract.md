# K4 R2 수정 계약

기준은 `int-20261011@584c280`와 원문 v2이다. `FINALS_K4_POLICY`는
`finals-unattended-v2`의 명시적 hash를 보존한 평가 후보다. 사전분류 프롬프트가
아직 신원 출력을 요구해 실호출 채택 조건을 충족하지 못했으므로 새 공개 실행은
차단한다. P2의 출력 문구 수정 후 새 hash와 새 검증이 필요하다. I3 기본 정책,
과거 정책 hash, 원문, 태깅·판정 revision과 원시 영수증은 보존한다.
push·배포·클라우드·운영 환경 파일 변경은 이 작업 범위 밖이다.

## 응답 신원

새 provider wire schema에서는 `claim_id`, `packet_sha256`, `replicate_id`를
제거한다. 사전분류 wire의 `claim_id`도 동일한 요청 신원 계약으로 제거한다.
모델이 이 필드를 반환하면 거절한다. 승인된 dispatch의 서버
요청에서만 신원을 조립한다. 내부 `LlmTags` DTO, 요청·테넌트·packet·replica
일치 검사, cache signature, 원문 인용·binding, 독립 provider ID 검사는 유지한다.
기존 실패 응답의 신원을 교체해 승인하는 경로는 없다. 저장 응답 평가에서도
그 실패는 유지한다. 추가 서비스 재시도는 없고 기존 provider의 형식 재시도
최대 1회는 기존 예약 및 누적 비용 상한 안에서만 실행한다.

## 수치와 범주

P1은 모델의 `present` 선택과 검증된 해당 주장 원문이 필요하다. 여러 수치를
선택했을 때에는 각 인용의 수치가 유일하고 같은 원자 span 안에 있으며,
선택 사이에 다른 수치를 추가하지 않는 경우에만 원문 연속 구간을 정규값으로
복원한다. unknown/conflict/unreadable은 승격하거나 absent로 바꾸지 않는다.
좌표 없는 단위 셀은 이미 검증된 같은 표 행의 유일한 원문 부분 인용으로
전달할 수 있다. 원래 셀 좌표·출처를 새로 만들지 않는다. 최신 값·단위·연도
연결과 해당 행 선택 검사는 그대로 적용한다.

`emissions_estimate` 모델 분류에는 검증된 해당 원문 또는 정확한 부모 표의
명시적 추정·산정 표시가 필요하다. 표시가 없는 모델 범주는 거부한다.
Scope3 관측의 산정 근거 검토 보류는 그 범주와 분리하며, 수치 요소나
응답 신원이 미해결이어도 보류 원인을 보존한다.

## 문맥과 시설

J7의 원자 span과 추출 hash는 유지한다. 접속절이 포함된 같은 원문 문장·bullet의
전체 문맥을 해석 입력과 `sentence_context`에 보존한다. 다른 bullet/문단의
목표를 차용하지 않는다. 명시적 미래 표지가 없는 이행 접속절의 goal 분류는
새 재태깅 대상으로 막는다. 해석 문맥은 인용 허용 catalog나 요소 충족이 아니다.

NAVER88 시설은 원래 표 격자, native 열 구획, 실제 머리글과 주장 위치를 함께
검증한다. 위치가 있는 머리 셀은 그 셀을 인용하고, 위치가 없는 inline 표제는
원래 표의 정확한 부분 인용 및 native 위치 증명을 보존한다. 가까운 제목만으로
시설을 추측하지 않는다. `source_dimensions.facility`는 검토용 원문 차원이며
모델 태깅·보증 연결·등급의 자동 충족으로 사용하지 않는다.

이 변경은 외부 HTTP API나 DB 구조를 바꾸지 않는다. 로컬 결과 스냅샷의 문장
문맥과 원문 차원 메타데이터가 추가되며, 이전 소비자는 기존 필드를 계속 읽는다.
rollback은 새 실행에서 I3 hash를 선택하는 방식이다. 저장된 K4 결과를 덮어쓰지 않는다.
