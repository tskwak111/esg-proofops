# K5 원자 주장 문맥 계약

`edf2f78`의 I4 분해·선택 결과를 유지하고 부모 문맥을 함께 전달한다.
새 실행은 `finals-unattended-v2`와 `FINALS_K5_POLICY`의 명시적 hash로 선택한다.
기본 I4 및 J3/J7/J8/K4의 기존 정책·프롬프트·원문·revision은 변경하지 않는다.

`sentence_context`에는 부모 문장, 개별 `SourceRef`, 검증 상태와
`rule_credit=false`를 저장한다. 앞·뒷절은 같은 페이지의 한 열에서 위치가
연속하고 미완결 어미가 있는 유일한 후보만 연결한다. 독립 문장, 짧은 제목,
다음 불릿, 다른 열은 연결하지 않는다. 원문 없는 주어를 만들지 않는다.
표는 명시적 origin grid의 한 셀과 그 열의 헤더만 참조한다. 저장량과 연간
흡수량, 공동 시설 범위·연구기관 표기는 부모 단위로 보존한다.
raw 코드포인트를 유지하며 표 grid의 NFC 좌표는 기존 원문 backmap으로 복원한다.

위치·원문 검증을 통과하지 않은 문맥은 candidate이다. 위치 없는 헤더는
unlocated/candidate를 유지한다. 문맥은 번호를 가진 근거·수치·연도·binding으로
승격되지 않는다. 선행분류와 요소 태깅은 같은 문맥을 읽지만 기존 인용 및
세 replica의 독립성·합의 가드를 계속 통과해야 한다.
부모 문맥의 최상급은 검증된 원문으로만 인정한다. 이를 생략하거나 원문
검증을 통과하지 않은 태깅은 보류하며 Python 등급 계산에 확정 입력으로 넣지 않는다.
선행분류 wire에서 문맥이 크기 제한 때문에 일부 누락되면 해당 처리를 중단한다.

API는 `ReviewProjection.sentence_context` 선택 필드만 추가한다.
기존 실행에는 이 필드를 반환하지 않는다. 검토 화면에서 부모 문맥과 원문
참조별 위치 열기를 제공한다. DB schema·쓰기 API·If-Match 계약 변경은 없다.
DB migration은 불필요하다. rollback은 새 실행에 기존 I4 hash를 선택하는 것이다.
기존 K5 실행을 I4로 재해석하지 않고, 저장된 태깅·보고서는 불변으로 유지한다.

`evaluation.k5_context_replay`는 저장된 I4/H1 선택만 재생하며 G1/A scorer와
정답 분모를 그대로 사용한다. 문자 1:1 proxy와 문맥 복원은 실모델·등급
정확도가 아니다. K5 실태깅과 AWS 시험은 not_run이다.
