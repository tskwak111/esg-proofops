실행 위치: esg-proofops-parser-lab 전용. 원본 esg-proofops-v2는 변경하지 않음.
웹: http://127.0.0.1:5175/analyze
로컬 분석 서버: 127.0.0.1:4240 (외부 인터페이스에 바인딩하지 않음)

키: 복사본 .env.openai.local의 OPENAI_API_KEY. 브라우저에 API 키를 입력하지 않음.

원인과 수정
1. sectionPicker는 인식 가능한 북마크가 2개 이상이면 본문 기반 판별을 무시했다.
   온실가스/에너지관리 북마크도 환경 구역 제목으로 인식하지 않았다.
   이제 환경 제목을 보완하고, 구역 경계를 보존하며 미분류 영역은 본문으로 판별한다.
2. Vite에는 /api/live-report 프록시가 없었고 해당 경로의 로컬 서버도 없었다.
   명시적인 로컬 모드에서만 /api를 로컬 서버로 연결한다.
   서버는 실제 SSH A100 Docling과 OpenAI Responses 구조화 출력으로 후보를 추출한다.
3. 모든 묶음 요청이 실패해도 빈 결과를 생성하고 완료 상태를 표시했다.
   성공한 묶음이 0이면 결과를 생성하지 않으며, 일부 성공은 일부 완료로 구별한다.

중요한 범위
로컬 HTTP 연결은 후보 추출 단계이며 전체 서비스의 완료된 분석 실행과 동일하지 않다.
묶음당 최대 16개 문단/셀에서 5개 주장 후보를 추출한다. 전체 주장 재현율을 보장하지 않는다.
Upstage 독립 교차검증, 요소 태깅, 최종 등급, DART 대사는 이 경로에서 실행하지 않는다.
후보의 source_verified는 false, decision은 null로 유지하며 화면에 미완료 범위를 표시한다.
차트 값은 이 경로에서 해석/판정하지 않는다. 기존 OpenAI 비전 검증 경로는 별도다.
스키마1.2 및 보고서 노출 설계 전용, 실제 정책/정답 승인 미설정은 그대로 유지한다.
