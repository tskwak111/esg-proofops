- 별도 Docling·SSH·기존 비전·Sol 회귀: **38 통과**. 추가 비용 초과 정산 테스트도 통과했다. 이 숫자들은 서로 중복되므로 합산하지 않는다.
- 웹 프로덕션 빌드와 TypeScript, Node replay 테스트 3개, Ruff, Python 316개 파일의 mypy, 아키텍처 검사 통과.

- 웹 컴포넌트 브라우저 검사 10개 통과. 과거 전용 fixture가 없는 1개는 실행하지 못했다.

Windows 오류 원인은 과도하게 긴 캐시/임시 경로, 100MB 테스트 입력이 그대로 포함된 테스트 이름, Windows에서 불가능한 파일명, POSIX 권한 비트 가정, 읽기 전용 파일 삭제, asyncio 내부 loopback 통신까지 차단하는 테스트 설정 등이었다. 검증 조건을 유지하면서 플랫폼에 맞게 수정했다. 비전 캐시 이름은 짧은 해시를 사용하며 기존 유료 응답 캐시는 계속 재사용한다.

Windows 테스트는 UTF-8과 짧은 전용 임시 경로를 설정하는 다음 명령으로 실행한다.

```powershell
powershell -NoProfile -File scripts/Test-Windows.ps1 -q
```

69개 건너뜀은 주로 저장소에 없는 고객 PDF·검토 승인 자료, 기존 macOS/Swift OCR, Windows 심볼릭 링크 권한 제약 때문이다. 이 경로들은 검증 완료가 아니다.

## 실제 PDF 및 Sol

- NAVER 217쪽 A100 Docling 결과: 표 127개, 기존 본문 15개·표 행 16개 확인 모두 통과. 그림 내부 텍스트 포함 및 표시용 제어문자 제거를 확인했다. 전체 표 의미 정확도의 정답 평가는 아니다.
- Upstage standard 217쪽, enhanced 180쪽 응답을 확보했다. enhanced 대상으로 분류된 182쪽 중 215·216쪽은 예산 예약 제한으로 보류됐다. 현재 누적 USD 9.195481460에 다음 요청의 USD 1.00 예약을 더하면 기존 USD 10 한도를 넘기므로 추가 호출하지 않았다. 이번 전체 비교의 신규 비용은 USD 8.327이다.
- 표 127개 중 122개가 행·열·헤더·원문 영역 대조 규칙상 검토 대상으로 남았다. 나머지 5개는 `not_numeric`이다. 즉, 수치표 전체의 합의가 입증된 것은 아니다. 122개가 모두 오답이라는 뜻도 아니다. 차트 검토 후보와 제어문자·숫자·표 구조 불일치 이유를 보존했다. 표 비교는 첫 헤더와 각 행의 문자열·병합 범위·좌표를 엄격히 비교하므로, 향후 개선에는 원문 근거를 유지하는 표 정렬과 정답 평가가 필요하다.
- 최종 복원 검증 상태는 `.local/docling-pilot/a100-full-crosscheck/summary.json`, 표별 요약은 `comparison.json`, 검색 가능한 대조 화면은 `review.html`이다. 대조 화면은 브라우저에서 30,186개 후보 행이 오류 없이 표시되는 것을 확인했다.
- 전체 217쪽의 저장 결과 복원 검증도 통과했다(`verified_replay=true`). 최종 그래프 21,870개 블록 중 13,985개는 충돌, 7,680개는 미검증, 205개는 위치 미확정이다. 이 결과를 승인된 사실로 취급하지 않는다. 전체 처리 4,472.25초에는 Upstage 호출, 원문 좌표 대조, 복원 검증이 포함되므로 Docling 단독 파싱 시간과 비교하지 않는다.
- Sol 직접 API로 101·105쪽 호출 성공. 보수적 누적 비용 기록 **USD 0.05726600**, 이 검증 경로의 누적 한도 **USD 4.00**. 계정 전체의 청구 한도를 설정한 것은 아니다.
- 원본 이미지와 비교한 101쪽 핵심 수치 8개 및 105쪽 차트 수치 12개가 출력에 있었다. 문구 변경과 목표/실제값의 평탄한 나열도 확인했다. 값의 존재 확인을 정확도·범례 연결 검증·전문가 승인으로 바꾸지 않는다.
