# 실제 원문 대조와 계정 매핑 초안

이 작업은 원문 수집 이후의 기술 검증·검토 준비다. 인증된 검토자의 승인,
정책 승인, 공시의 회계 적정성 판정을 대신하지 않는다.

## 재실행

```bash
uv run --no-sync python -m evaluation.reconciliation_source_audit \
  --manifest COLLECTION_JSON --store ORIGINALS_DIRECTORY \
  --corp-code DART_CORP_CODE --fy 2024 --rcept-no PINNED_RECEIPT \
  --consolidation consolidated --output NEW_AUDIT_JSON
```

SR PDF를 함께 점검하려면 `--sr-sources SR_SOURCES_JSON`을 추가한다.
입력 형식은 기존 `reconciliation-sr-sources-1`과 같다. 출력은 새 파일만 허용한다.
실제 API 키와 네트워크는 필요 없다. 원문 해시·기업·연도·접수번호를 검사하고,
원문에서 후보를 다시 만든 뒤 후보별 해시·문자 또는 페이지 위치·인용을 검사한다.
이 동일 구현의 재현 검사는 독립적인 추출 정확도 평가가 아니다.

기본 DART 후보 상한은 2,000개다. `candidate_limit.truncated=true`이면
전체 검색 완료로 해석할 수 없다. 별도로 추가한 SR 후보 수는 이 상한과 구분한다.
`account_mapping_draft.inventory`에는 선택된 재무제표 행의 원래 계정 ID,
명칭, 재무제표 구분, 기간 표기, 원금액과 출처를 보존한다.

## 삼성전자 실제 PDF에서 확인한 C1–C4 검토 자료

원문: [삼성전자 지속가능경영보고서 2025 한국어](https://www.samsung.com/sec/sustainability/media/pdf/Samsung_Electronics_Sustainability_Report_2025_KOR.pdf).
물리 페이지와 인쇄 페이지가 일치하는 아래 4개 페이지를 PDFium으로 렌더링하고
추출 문자열과 시각적으로 대조했다. 원문 SHA-256은
`342a99a14d7c32b4e66cbbf977cc89dc79044ccc7c5e71367fb476c14538c8c5`다.

| 항목 | 위치 | 확인 사실과 처리 |
|---|---|---|
| C1 조직경계 | 86쪽 보고 범위 | 재무는 연결기준이며 환경성과에는 생산거점 외 판매·연구소 등이 포함된다는 설명이 있다. 연결대상 법인집합과 환경 사업장집합의 동일성은 이 문단만으로 확정하지 않는다. |
| C2 기간 | 68쪽 환경성과 표, 86쪽 보고기간 | 68쪽 표에는 2022·2023·2024년 열이 있으며 시장기반 2024년 값은 14,889천 톤CO₂e다. 각주의 산정범위 변경을 함께 확인했다. 보고서 전체의 기본 기간만으로 모든 지표를 2024년으로 처리하지 않는다. |
| C3 투자 약정 | 8쪽 중대 주제 표 | 2030년까지 환경경영 과제에 7조 원 이상 투자하는 목표가 있다. 하한·누적기간을 가진 약정이므로 정확한 단년도 집행액으로 정규화하지 않는다. 시작연도·대상 계정·비교 배수 승인은 별도다. |
| C4 분류 매출 비율 | 84쪽 SASB 대조표 | EPEAT 관련 제품별 매출 비율과 각주가 있다. 각주 기준은 **2023년 북미(미국·캐나다) 매출**이다. 2024년 연결 전체 매출을 분모로 자동 연결하면 안 된다. 정의·산식·제품별 분모의 추가 검토가 필요하다. |

위 결과는 에이전트의 출처 관찰이다. 사람의 검토 이력이나 승인 레지스트리를
만들지 않았으며, `search_complete` 또는 `policy_approved`를 올리지 않는다.
기존 초안의 보고기간 인용만으로 C2가 완료됐다고 처리하지 않는다.

## C3 계정 초안의 사용법

계정명/ID에서 유형·무형자산 취득을 찾되 현금흐름표(`CF`) 행만 취득 후보로
표시한다. 재무상태표(`BS`)의 자산 잔액, 투자활동 전체 현금흐름,
자산 처분은 자동으로 CAPEX 합계에 넣지 않는다. 후보 분류는 문자열 탐색 보조이며
표준 계정의 회계 의미나 적용 정책을 승인하지 않는다.

모든 행의 `include_in_capex`는 `null`, 허용 계정 목록은 빈 목록,
`approved=false`, C3 임계값은 `null`이다. 담당자는 현금/발생 기준,
무형자산·리스·사업결합 포함 여부, 총액/순액·부호·통화·기간·중복 처리와
허용 계정·배수를 결정하면 된다. 결정 전에도 원문 관찰과 후보 검증은 재실행할 수 있다.

## 정정공시 처리에서 확인한 경계

동서의 2024년 최초 사업보고서 접수번호 `20250313000532`와 현재 재무제표
응답의 `20251210000195`가 달라 최초 수집이 차단됐다. 실패 수집 기록을 보존하고,
정정 사업보고서 목록을 확인한 뒤 정정본의 재무제표·문서·XBRL을 새로 수집했다.
최초 원문과 정정 재무제표를 혼합하지 않았으며 접수번호 검증을 완화하지 않았다.
